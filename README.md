# Uppsala / Photo Archive

## Publicera på GitHub Pages
1. Skapa ett **Public** repository på GitHub, exempelvis `uppsala-photo-archive`.
2. Ladda upp `index.html`, `style.css` och mappen `images` till huvudmappen.
3. Öppna **Settings → Pages**.
4. Under **Build and deployment** välj **Deploy from a branch**, branch `main`, folder `/(root)` och spara.
5. När publiceringen är klar visas webbadressen i Settings → Pages.

## Lägg till dina bilder
- Lägg en bred omslagsbild i `images` med filnamnet `hero.jpg`.
- Seriekorten är färgade platshållare just nu. Du kan byta ut dem senare mot egna bilder genom att ändra `background-image` för klasserna `.city`, `.study`, `.party` osv. i `style.css`.
- Byt `hello@example.com` mot din egen mejladress.
